# SMART JARVIS

- Memories are stored in the local SQLite database and can be reviewed or deleted from the Memory & context panel.
- Each enabled memory is assembled into a short system-context section for provider chat requests.
- Text documents are limited to 2 MB and supported UTF-8 formats: TXT, MD, CSV, JSON, LOG, YAML, YML.
- Uploaded document text is stored in the local database. Only short excerpts are sent to the selected provider with each relevant chat request.
- Memory and document operations require no account or integration. There is no silent web browsing or external fact retrieval.
