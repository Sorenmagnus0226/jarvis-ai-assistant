# Smart Kaizen

- Memories are stored in the local SQLite database and can be reviewed or deleted.
- Enabled memories are assembled into provider chat context.
- Supported text documents: TXT, MD, CSV, JSON, LOG, YAML, and YML.
- Documents are limited to 2 MB and UTF-8 text.
- Uploaded document excerpts are sent only when included in a chat request.
- There is no silent web browsing or external fact retrieval.
